# 三国武将自动战斗 Roguelike — 基础规则文档

## 游戏概述

玩家组建一支三国武将队伍，通过最多30回合的自动战斗闯关。每回合面临敌人难度选择、武将招募或升级等决策，核心策略在于阵容搭配、升级分配和资源管理。游戏为计分制，以生存回合数为主要评价指标。

**技术栈**：React + TypeScript + Vite，部署至 Vercel，纯前端单机游戏。

---

## 回合结构

一局游戏最多 **30 回合**，每回合流程如下：

```
回合开始
  → 选将 / 升级（根据回合类型）
  → 选择敌人难度（简单 / 困难）
  → 自动战斗
  → 结算金币
  → [每5回合] Boss战 → 商店
回合结束
```

### 回合类型

| 回合 | 事件 | 说明 |
|------|------|------|
| 1, 2, 4, 7, 10 | 选将 | 从未拥有的武将中随机出现3个，选1个加入队伍 |
| 5, 10, 15, 20, 25, 30 | Boss战 | 特殊Boss敌人，有独特机制 |
| Boss战后 | 商店 | 额外插入的购物环节，不占回合数 |
| 其余回合 | 升级 | 从已拥有的武将中随机出现2个，选1个进行升级 |

> 注：第10回合同时触发选将和Boss战。选将在战斗前进行。

## 战斗系统

### ATB（Active Time Battle）机制

- 每个单位（武将和敌人）都有 **行动速度** 属性
- 每个单位拥有一个 **行动条**，随时间按速度值增长
- 行动条满时，该单位执行行动（释放技能）
- 行动完毕后行动条清零，重新积累

### 全自动战斗

战斗完全自动进行，玩家观战。每个武将的技能释放遵循预设AI逻辑：

- **单体伤害**：攻击血量最低的敌人（补刀优先）
- **范围伤害**：当敌人数量 ≥ 3 时使用范围技能，否则普攻
- **治疗**：治疗血量百分比最低的队友，满血时普攻
- **Buffer**：优先给伤害最高的队友加buff，buff已存在时普攻
- **嘲讽坦克**：开场释放嘲讽，嘲讽持续期间普攻，到期后刷新嘲讽
- **控制**：优先控制行动条最满的敌人（打断即将行动的敌人）

### 目标选择

- **敌方单位**：在没有被嘲讽的情况下，攻击目标随机选择
- **被嘲讽时**：只能攻击嘲讽者
- **己方治疗/buff**：按AI逻辑选择队友

### 战斗结束条件

- **胜利**：所有敌人被击败
- **失败**：所有武将被击倒 → 游戏结束

## 武将系统

### 招募

- 在第 **1、2、4、7、10** 回合招募新武将
- 每次从未拥有的武将池中随机出现 **3 个**，玩家选择 **1 个**
- 最终队伍最多 **5 个**武将

### 升级

- 在非选将回合，从已拥有的武将中随机出现 **2 个**，选 **1 个**升级
- 纯随机，无保底机制
- 升级效果显著：
  - 基础属性大幅提升（生命值、攻击力、防御力、速度）
  - 技能效果增强（伤害倍率、治疗量、控制时长等）
- 升级无上限，同一武将可多次升级

### 死亡与复活

- 武将在战斗中可以被击倒
- **每场战斗开始时全员满血复活**
- 单场战斗中全员被击倒 = 游戏结束

## 敌人系统

### 难度选择

每回合战斗前，玩家在两种敌人之间选择：

| 难度 | 金币奖励 | 敌人特点 |
|------|----------|----------|
| 简单 | ~100 金币（90-110浮动） | 敌人数量较少，数值较低 |
| 困难 | ~150 金币（130-170浮动） | 敌人数量更多，数值更高 |

### 敌人类型

敌人使用与武将相同的ATB系统，但以 **伤害为主**：
- **普通近战**：单体物理伤害
- **远程射手**：单体远程伤害，速度较快
- **法师**：范围魔法伤害
- **精英**：高属性单位，可能附带debuff

### Boss（每5回合）

- 第 5、10、15、20、25、30 回合为Boss战
- Boss为单个高属性单位，拥有特殊机制：
  - **特殊技能**：范围攻击、全体debuff、召唤小兵等
  - **阶段机制**：血量降至一定比例时切换行为模式
  - Boss难度随回合递增
- Boss战同样有简单/困难选择，困难Boss奖励更高

## 经济系统

### 金币获取

- 击败简单敌人：**90-110 金币**
- 击败困难敌人：**130-170 金币**
- Boss战额外奖励：**简单+50 / 困难+80**

### 商店

- **触发时机**：每次Boss战后额外插入，不占回合数
- **商品**：随机出现 **3 件物品**
- **价格**：每件约 **500 金币**（450-550浮动）
- **规则**：
  - 只能购买负担得起的物品
  - 每次商店可购买多件（如果金币足够）
  - 未购买的物品消失，不会保留到下次
  - 武将绑定物品只在拥有该武将时才会出现

---

## 计分系统

### 主要指标：生存回合数

- 游戏结束时的回合数即为分数
- 通关30回合为满分
- 分数 = 存活到的回合数

### 附加信息（不影响分数，供参考）

- 选择困难敌人的次数
- 击败Boss数量
- 最终金币余额
- 阵容组成

## 游戏流程示例

```
第1回合：选将（3选1）→ 选难度 → 战斗 → 结算
第2回合：选将（3选1）→ 选难度 → 战斗 → 结算
第3回合：升级（2选1）→ 选难度 → 战斗 → 结算
第4回合：选将（3选1）→ 选难度 → 战斗 → 结算
第5回合：升级（2选1）→ 选难度 → Boss战 → 结算 → 商店
第6回合：升级（2选1）→ 选难度 → 战斗 → 结算
第7回合：选将（3选1）→ 选难度 → 战斗 → 结算
...
第10回合：选将（3选1）→ 选难度 → Boss战 → 结算 → 商店
第11-14回合：升级 → 战斗
第15回合：升级 → Boss战 → 商店
...
第30回合：升级 → Boss战（最终Boss）→ 结算 → 游戏结束
```
