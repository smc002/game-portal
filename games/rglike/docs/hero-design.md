# 武将技能设计文档

## 设计原则

- 10个武将覆盖6种定位：单体伤害、范围伤害、治疗、Buffer、嘲讽坦克、控制
- 每个武将有1个被动特性 + 1个主动技能（全自动释放）
- 升级时所有数值获得显著提升（约20-30%每级）
- 武将间存在协同效应，鼓励多样化阵容

## 基础属性说明

| 属性 | 说明 |
|------|------|
| 生命值（HP） | 被击倒的血量阈值 |
| 攻击力（ATK） | 影响技能伤害/治疗量 |
| 防御力（DEF） | 减少受到的伤害 |
| 速度（SPD） | 行动条增长速率 |

## 武将列表

### 1. 赵云 — 单体伤害（刺客型）

**定位**：高爆发单体输出，擅长击杀残血目标

| 属性 | 基础值 | 每级成长 |
|------|--------|----------|
| HP | 800 | +200 |
| ATK | 150 | +40 |
| DEF | 60 | +15 |
| SPD | 110 | +5 |

**被动 — 龙胆**：攻击生命值低于30%的目标时，伤害提升50%

**主动技能 — 七进七出**：对单体敌人造成 ATK×180% 的伤害。若该次攻击击杀目标，立即获得50%行动条。

**AI逻辑**：优先攻击血量最低的敌人

**升级增强**：
- 被动触发阈值提升（30% → 35% → 40%...）
- 技能倍率提升（180% → 200% → 220%...）

---

### 2. 关羽 — 单体伤害（战士型）

**定位**：稳定高伤害输出，持续作战能力强

| 属性 | 基础值 | 每级成长 |
|------|--------|----------|
| HP | 1100 | +280 |
| ATK | 140 | +35 |
| DEF | 80 | +20 |
| SPD | 90 | +4 |

**被动 — 武圣**：每次攻击后，下次攻击伤害额外增加 ATK×15%（可叠加，最多5层，受到攻击时清零）

**主动技能 — 青龙偃月**：对单体敌人造成 ATK×200% 的伤害，无视目标20%的防御力

**AI逻辑**：攻击当前血量最高的敌人（优先削减主要威胁）

**升级增强**：
- 被动叠加上限提升（5层 → 6层 → 7层...）
- 无视防御比例提升（20% → 25% → 30%...）

---

### 3. 张飞 — 嘲讽坦克

**定位**：吸引敌方火力，保护队友

| 属性 | 基础值 | 每级成长 |
|------|--------|----------|
| HP | 1800 | +450 |
| ATK | 80 | +15 |
| DEF | 120 | +30 |
| SPD | 70 | +3 |

**被动 — 燕人之勇**：生命值低于40%时，防御力提升30%

**主动技能 — 当阳桥喝**：对所有敌人施加嘲讽，持续2次敌人行动。同时对所有敌人造成 ATK×80% 的伤害并降低其速度10%，持续2次行动。

**AI逻辑**：嘲讽效果消失后立即重新施放；嘲讽存在期间进行普通攻击（ATK×100%，攻击随机敌人）

**升级增强**：
- 嘲讽持续行动次数提升（2次 → 3次...）
- 被动触发阈值提升（40% → 45%...）
- 减速效果提升（10% → 15%...）

---

### 4. 诸葛亮 — 范围伤害（法师型）

**定位**：高范围伤害，清理敌方小兵

| 属性 | 基础值 | 每级成长 |
|------|--------|----------|
| HP | 700 | +160 |
| ATK | 160 | +45 |
| DEF | 40 | +10 |
| SPD | 95 | +5 |

**被动 — 八阵图**：范围技能每额外命中1个目标，伤害提升5%（如命中4个目标，总计+15%）

**主动技能 — 火烧连营**：对所有敌人造成 ATK×120% 的伤害。敌人数量 ≥ 3 时额外造成 ATK×30% 的灼烧伤害（在目标下次行动时触发）。

**AI逻辑**：始终使用范围技能

**升级增强**：
- 基础倍率提升（120% → 140% → 160%...）
- 灼烧伤害提升（30% → 40%...）
- 被动每目标加成提升（5% → 7%...）

---

### 5. 周瑜 — 范围伤害（持续型）

**定位**：持续范围伤害，适合消耗战

| 属性 | 基础值 | 每级成长 |
|------|--------|----------|
| HP | 750 | +170 |
| ATK | 145 | +40 |
| DEF | 45 | +12 |
| SPD | 100 | +5 |

**被动 — 火攻**：攻击附带灼烧效果，每次行动对目标造成 ATK×20% 的持续伤害，持续2次目标行动

**主动技能 — 赤壁之焰**：对所有敌人造成 ATK×100% 的伤害，并将已有灼烧效果的持续时间刷新并叠加1层（每层独立计算伤害）

**AI逻辑**：始终使用范围技能

**升级增强**：
- 灼烧基础伤害提升（20% → 25%...）
- 技能倍率提升（100% → 120%...）

---

### 6. 华佗 — 治疗

**定位**：队伍治疗核心，保障团队续航

| 属性 | 基础值 | 每级成长 |
|------|--------|----------|
| HP | 900 | +220 |
| ATK | 120 | +30 |
| DEF | 55 | +15 |
| SPD | 105 | +5 |

**被动 — 妙手回春**：治疗效果额外附带一个持续回复效果，在目标下次行动时恢复 ATK×20% 的生命值

**主动技能 — 青囊术**：治疗生命值百分比最低的队友，恢复 ATK×180% 的生命值。若目标生命值低于30%，治疗量提升50%。

**AI逻辑**：
- 队伍中有人血量 < 70% 时使用治疗
- 全员血量 > 70% 时进行普通攻击（ATK×80%，攻击随机敌人）

**升级增强**：
- 治疗倍率提升（180% → 210%...）
- 被动回复提升（20% → 25%...）
- 紧急治疗阈值放宽（30% → 35%...）

---

### 7. 貂蝉 — 控制（魅惑型）

**定位**：控制敌方核心单位，打断敌人节奏

| 属性 | 基础值 | 每级成长 |
|------|--------|----------|
| HP | 750 | +180 |
| ATK | 130 | +30 |
| DEF | 45 | +12 |
| SPD | 115 | +6 |

**被动 — 闭月**：被控制的敌人受到的伤害增加15%

**主动技能 — 倾国倾城**：魅惑1个敌人，使其行动条清零并跳过下次行动。同时对目标造成 ATK×100% 的伤害。

**AI逻辑**：优先控制行动条最满的敌人（即将行动的敌人）

**升级增强**：
- 被动增伤提升（15% → 20%...）
- 技能伤害倍率提升（100% → 120%...）
- 有一定概率控制2个目标（0% → 15% → 25%...）

---

### 8. 司马懿 — 控制（减速型）

**定位**：全体减速控制，拖慢敌方整体节奏

| 属性 | 基础值 | 每级成长 |
|------|--------|----------|
| HP | 850 | +200 |
| ATK | 125 | +30 |
| DEF | 60 | +15 |
| SPD | 100 | +5 |

**被动 — 隐忍**：战斗开始时获得一个护盾，吸收 HP×15% 的伤害

**主动技能 — 鹰视狼顾**：降低所有敌人20%的速度，持续2次敌人行动。同时对所有敌人造成 ATK×90% 的伤害。

**AI逻辑**：
- 减速效果不存在时释放技能
- 减速存在时普通攻击行动条最满的敌人（ATK×100%）

**升级增强**：
- 减速幅度提升（20% → 25%...）
- 护盾比例提升（15% → 18%...）
- 技能伤害提升（90% → 110%...）

---

### 9. 刘备 — Buffer（增益型）

**定位**：强化队友输出，提升团队整体战斗力

| 属性 | 基础值 | 每级成长 |
|------|--------|----------|
| HP | 1000 | +250 |
| ATK | 100 | +25 |
| DEF | 70 | +18 |
| SPD | 85 | +4 |

**被动 — 仁德**：队友被击倒时，剩余存活队友攻击力提升10%（可叠加）

**主动技能 — 桃园结义**：为攻击力最高的队友施加增益，提升其攻击力25%和速度15%，持续3次该队友行动。

**AI逻辑**：
- buff不存在时对攻击力最高的队友释放buff
- buff存在时普通攻击随机敌人（ATK×100%）

**升级增强**：
- 攻击力增益提升（25% → 30%...）
- 速度增益提升（15% → 18%...）
- buff持续行动次数提升（3次 → 4次...）

---

### 10. 孙尚香 — Buffer（攻速型）

**定位**：提升全队攻速，加快整体行动节奏

| 属性 | 基础值 | 每级成长 |
|------|--------|----------|
| HP | 850 | +200 |
| ATK | 120 | +30 |
| DEF | 50 | +13 |
| SPD | 120 | +6 |

**被动 — 弓腰姬**：自身速度超过100时，每多10点速度，普攻伤害提升5%

**主动技能 — 巾帼之舞**：为所有队友提升20%速度，持续2次各自行动。同时对随机1个敌人造成 ATK×130% 的伤害。

**AI逻辑**：
- 速度buff不存在时释放技能

**升级增强**：
- 速度增益提升（20% → 25%...）
- 技能伤害提升（130% → 150%...）
- 被动加成比例提升（5% → 7%...）

## 武将协同效应

以下阵容组合会产生额外的策略效果（非系统加成，而是机制层面的自然协同）：

| 组合 | 协同说明 |
|------|----------|
| 张飞 + 关羽/赵云 | 张飞嘲讽吸引火力，保护脆皮输出稳定叠伤 |
| 诸葛亮 + 周瑜 | 双范围法师，周瑜灼烧+诸葛亮爆发，快速清场 |
| 貂蝉 + 赵云 | 貂蝉增伤debuff + 赵云斩杀，高效清除高威胁目标 |
| 刘备 + 关羽 | 刘备buff关羽，关羽高攻击力最大化buff收益 |
| 孙尚香 + 华佗 | 攻速加成让华佗更频繁治疗，提升团队续航 |
| 司马懿 + 诸葛亮 | 司马懿减速拖延敌人，诸葛亮灼烧持续消耗 |
| 张飞 + 华佗 | 坦克+奶，华佗优先治疗低血量的张飞，经典前排组合 |
| 刘备 + 孙尚香 | 双Buffer叠加，全队攻击力和速度双提升 |
