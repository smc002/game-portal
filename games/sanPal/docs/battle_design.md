# sanPal：战斗系统设计文档

## 一、战斗概述

回合制 1v1 战斗。双方各派出 1 名武将对战，可切换后备武将。每回合双方各选择一个行动，按速度排序依次执行。战斗引擎在 `BattleEngine.ts` 中实现，全部逻辑在客户端同步运行。

---

## 二、回合流程

### 完整回合时序

```
1. 回合开始
   ├─ 玩家方回合开始结算（天气伤害、状态伤害、被动触发）
   ├─ 敌方回合开始结算（同上）
   ├─ Boss被动触发（张角每3回合换天气）
   └─ 若任一方死亡 → 处理击败

2. 行动阶段
   ├─ 玩家选择行动（技能/换将）
   ├─ AI选择行动（基于评分算法）
   ├─ 按优先级和速度排序，决定先后手
   └─ 依次执行两方行动：
       ├─ 混乱自伤检测（33%概率）
       ├─ 命中判定
       ├─ PP消耗
       ├─ 伤害计算（支持多段攻击）
       │   ├─ 属性克制
       │   ├─ STAB加成
       │   ├─ 天气修正
       │   ├─ 暴击判定
       │   ├─ 被动修正（攻方+防方）
       │   ├─ 护盾吸收
       │   └─ 反击伤害
       ├─ 技能附加效果（状态/增减/天气/治疗/护盾）
       ├─ 被动技能触发（陆逊/庞统/徐晃）
       └─ 击败检测

3. 回合结束
   ├─ 天气持续回合 -1（归零则恢复晴天）
   └─ 回合数 +1
```

### 玩家行动选项

| 行动 | 说明 | 消耗回合 |
|------|------|----------|
| 使用技能 | 从当前武将已解锁且PP>0的技能中选择 | 是 |
| 切换武将 | 换上队伍中另一名存活武将（被锁定时不可用） | 是 |
| 使用道具 | 尚未启用 | — |

### AI行动逻辑

敌方AI（`AIController.ts`）基于评分算法选技能：
- 基础分 = 技能威力
- 属性克制目标：×1.5
- 被目标属性克制：×0.5
- HP<40% 时辅助技能 +50 分
- 随机噪声 +0~20
- 选择最高分技能

> AI不会主动换将。

## 三、伤害计算

### 公式

```
基础伤害 = 技能威力 × (攻击力 / 防御力) × 0.5 + 5

攻击力 = 有效属性 × 被动倍率
  - 武技：ATK（含stage加成）× getPassiveStatMultiplier(atk)
  - 计策：INT（含stage加成）× getPassiveStatMultiplier(int)

防御力 = 有效属性 × 被动倍率
  - 武技：DEF（含stage加成）× getPassiveStatMultiplier(def)
  - 计策：RES（含stage加成）× getPassiveStatMultiplier(res)

最终伤害 = 基础伤害 × STAB × 属性克制 × 天气修正 × 暴击 × 随机波动 × 灼烧减益 × 被动加成
```

### 各修正值

| 修正项 | 条件 | 倍率 |
|--------|------|------|
| STAB | 技能属性 = 武将属性 | ×1.2 |
| 属性克制 | 火→金→木→土→水→火 | ×2.0 |
| 属性被克 | 反向 | ×0.5 |
| 天气增幅 | 烈日+火 / 暴雨+水 / 狂风+木 | ×1.3 |
| 天气削弱 | 烈日+水 / 暴雨+火 | ×0.7 |
| 沙尘+土 | — | ×1.2 |
| 暴击 | 基础5% + 弓手10% + 被动加成 | ×1.5 (武圣/无双 ×2.0) |
| 灼烧减益 | 攻击方灼烧 + 武技 | ×0.75 |
| 赤壁之焰 | 周瑜对灼烧目标用计策 | ×1.25 |
| 火烧连营 | 烈日天气 | ×1.5 |
| 随机波动 | 固定 | ×0.9~1.1 |

### 护盾吸收

伤害优先扣除护盾值，余量扣HP：
```
若有护盾：absorbed = min(shieldValue, damage), 余量 = damage - absorbed
HP减少 = 余量
```

### 多段攻击

技能可定义 `multiHit: [min, max]`，每次命中独立计算伤害：
- 连珠箭：2~4 次
- 过五关：固定 3 次

战斗日志逐次显示，最后汇总总伤害。

## 四、五行属性系统

### 克制关系（五行相克）

```
火 → 金 → 木 → 土 → 水 → 火
```

| 攻击属性 | 克制目标 | 伤害倍率 |
|----------|----------|----------|
| 火 | 金 | ×2.0 |
| 金 | 木 | ×2.0 |
| 木 | 土 | ×2.0 |
| 土 | 水 | ×2.0 |
| 水 | 火 | ×2.0 |
| 反向 | — | ×0.5 |
| 无关 | — | ×1.0 |

### STAB（同属性加成）

技能属性 = 武将本体属性时，伤害 ×1.2。

> 注意：一个武将可能拥有不同属性的技能（如诸葛亮为木属性，但拥有火属性的"借东风"技能），非同属性技能不享受STAB。

### 天气效果

| 天气 | emoji | 效果 | 典故 |
|------|-------|------|------|
| 晴天 | ☀️ | 无 | 默认 |
| 烈日 | 🔥 | 火技能+30%，水技能-30% | 火烧连营 |
| 暴雨 | 🌧️ | 水技能+30%，火技能-30%，每回合自动解除灼烧 | 水淹七军 |
| 浓雾 | 🌫️ | 武技命中率-30%，计策不受影响 | 草船借箭 |
| 狂风 | 🌪️ | 木技能+30%，弓手SPD+50% | 借东风 |
| 沙尘 | ⛰️ | 土技能+20%，非土属性武将每回合损失6%最大HP，土属性DEF+20%（通过被动） | 沙场征战 |

### 天气规则

- 初始为晴天
- 通过技能（如"赤壁烈焰"、"暴雨术"、"借东风"、"沙尘术"）改变天气
- 新天气覆盖旧天气
- 天气持续 5 回合后自动消散
- 张角Boss被动：每 3 回合随机切换天气

### 改变天气的技能

| 技能 | 武将 | 目标天气 |
|------|------|----------|
| 赤壁烈焰 | 周瑜 | 烈日 |
| 暴雨术 | （通用水系） | 暴雨 |
| 借东风 | 诸葛亮 | 狂风 |
| 沙尘术 | 司马懿/庞统 | 沙尘 |

## 六、状态效果系统

### 异常状态（同时最多 1 个，新的覆盖旧的）

| 状态 | emoji | 效果 | 持续 | 回合开始结算 |
|------|-------|------|------|-------------|
| 灼烧 | 🔥 | ATK×0.75（武技），每回合-8%最大HP | 3回合 | 暴雨天气自动解除 |
| 冰冻 | 🧊 | 无法行动 | 每回合33%概率自行解除 | 未解冻则跳过行动 |
| 中毒 | ☠️ | 每回合损失6~16%最大HP（递增） | 持续到战斗结束 | 伤害随时间增加 |
| 混乱 | 😵 | 33%概率攻击自己（公式：40×ATK/DEF×0.5） | 3回合 | 在行动选择时检测 |
| 眩晕 | ⚡ | 跳过下一次行动 | 1次后自动解除 | 跳过并清除 |

### 状态免疫

- 祝融（p_huoshen）：免疫灼烧

### 状态持续回合递减

- 每回合开始时 turnsLeft -1，归零则清除
- 冰冻不递减，而是每回合独立判定 33% 解除
- 中毒 turnsLeft = -1（持续到战斗结束）

### 属性增减（可与异常状态共存）

每项属性（ATK/DEF/INT/RES/SPD）可在 -3 ~ +3 级之间调整：

| 等级 | -3 | -2 | -1 | 0 | +1 | +2 | +3 |
|------|-----|-----|-----|---|------|------|------|
| 倍率 | ×0.4 | ×0.6 | ×0.8 | ×1.0 | ×1.25 | ×1.5 | ×2.0 |

- 切换武将下场时属性增减**清零**

### 特殊状态

| 状态 | 效果 | 来源 |
|------|------|------|
| 护盾 | 吸收等量伤害后消失（有数值） | 重甲、五谷丰登 |
| 反击 | 被武技攻击时反弹30%伤害（持续2回合） | 七进七出、反弹 |
| 锁定 | 无法切换武将（持续2回合） | 连环计 |
| 防御姿态 | 受攻击时伤害减免80%，并触发附加效果（持续1回合，被攻击消耗） | 坚守/反击架势/破釜沉舟 |

### 防御指令（第三技能）

所有武将的第三技能为防御技能，消耗1能量，优先级+2（绝对先制）：

| 技能 | 附加效果 | 分配武将 |
|------|----------|---------|
| 坚守 | 受攻击时80%减伤 + 获得20%最大HP护盾 | 多数武将 |
| 反击架势 | 受攻击时80%减伤 + DEF+1级 | 关羽、赵云、曹操等 |
| 破釜沉舟 | 受攻击时80%减伤 + ATK+1级 | 吕布、孙策、魏延等 |

### 击杀替补规则

- 武将被击杀后，下一位存活武将自动上场
- **替补上场的武将可以在下一回合正常行动**（不跳过回合）
- 主动换将仍需消耗当回合行动，换上的武将在换将发生的回合无法行动

## 八、先制与行动顺序

### 决定规则

1. **优先级（priority）** 高的先行动
   - 切换武将 = 优先级 99（绝对先手）
   - 技能自带优先级：+2(绝对先制) > +1(先制) > 0(普通) > -1(后制)
   - 赵云被动：HP<30%时技能优先级提升到至少+1
2. 优先级相同时，比较 **有效SPD**
   - 计入 stage 加成 + 被动倍率 + 天气加成
3. SPD 也相同时，50/50 随机

### 先制技能列表

| 技能 | 优先级 | 武将 |
|------|--------|------|
| 坚守/反击架势/破釜沉舟 | +2 | 全武将（防御技能） |
| 突袭 | +1 | 张辽、典韦 |
| 拖刀计 | +1 | 关羽 |
| 七进七出 | +1 | 赵云、孙策 |

## 九、Debuff→Exploit 组合系统

核心设计：每位组合武将的第1技能（低消耗）施加debuff，第2技能（高消耗）利用debuff打出高额伤害。

### 组合一览

| 武将 | 技能1（Debuff） | 技能2（Exploit） | 组合逻辑 |
|------|----------------|-----------------|---------|
| 周瑜 | 火攻（60%灼烧） | 连环计（灼烧×1.5） | 先灼烧再锁定爆发 |
| 陆逊 | 纵火（50%灼烧） | 火烧连营（灼烧×1.5） | 叠灼烧再火攻 |
| 诸葛亮 | 奇门术（40%混乱） | 天雷（混乱×1.5） | 先混乱再雷击 |
| 司马懿 | 暗算（50%中毒） | 权谋（中毒×1.5） | 先下毒再致命一击 |
| 关羽 | 威压（DEF-1） | 青龙斩（属性降低×1.5） | 先破防再斩杀 |
| 张飞 | 怒喝（DEF-1+20%晕） | 丈八蛇矛（属性降低×1.5） | 先震慑再横扫 |
| 赵云 | 寒枪刺（25%冰冻） | 龙胆枪（冰冻×2.0） | 先冰冻再碎冰 |
| 庞统 | 落凤（RES-1） | 连环阵（属性降低×1.5） | 先降谋略再混乱 |
| 曹操 | 离间（ATK-1） | 挟天子（属性降低×1.5） | 持续削弱叠加 |

### 条件加成机制

技能可定义以下条件加成字段：
- `bonusVsStatus: { status, multiplier }` — 目标有指定状态时伤害乘以multiplier
- `bonusVsDebuffed: number` — 目标有任意负面属性等级时伤害乘以该值
