# sanPoker：三谋战斗规则参考文档

> 本文档基于《三国：谋定天下》（以下简称"三谋"）的实际战斗机制整理，作为 sanPoker 战斗引擎的参考。
> sanPoker 会在此基础上**简化**（固定 3 武将、MVP 阶段不实装兵种克制、阵营加成等），但核心机制（战法 4 分类、8 回合、先攻系统、负面状态）保持一致。
>
> 后续下注博弈部分在独立文档中展开。

---

## 一、战斗基本规则

### 队伍组成

- 每方 3 名武将，部署于 3 个位置（前锋 / 中军 / 大营 —— 官方阵法位）
- 每位武将携带 **2 个战法**（sanPoker MVP 固定 2 战法，三谋正式版最多 3 个）
- 每位武将有独立的属性值与兵力

### 战斗节奏

- **每场战斗固定 8 回合**
- 每回合所有存活武将各行动 1 次
- 行动顺序由**先攻**决定；**先攻差 > 70 时，先攻高者必定先手**；差值 ≤ 70 时按概率先后
- 任一方 3 武将兵力全部归零则立即战败

### 胜负判定

1. 一方 3 武将兵力全部归零 → 对方胜
2. 8 回合结束仍有存活武将 → 按**剩余总兵力百分比**判定（高者胜）
3. 兵力百分比相同 → 平局

## 二、武将属性（三谋官方术语）

| 属性 | 作用 |
|------|------|
| **武力** | 影响武力类战法伤害 |
| **智力** | 影响谋略类战法伤害 |
| **统率** | 减免受到的伤害（武力与谋略均减免） |
| **先攻** | 决定每回合行动顺序；差值 > 70 时必先手 |
| **兵力** | 相当于 HP，归零则武将阵亡 |

> **注**：三谋无独立"速度"属性，先攻即为速度概念。统率是综合防御属性，不区分物防/法防。

### sanPoker MVP 属性基准（简化设计）

为保证 2–3 分钟快速战斗，sanPoker 采用较小数值：

| 原型 | 兵力 | 武力 | 智力 | 统率 | 先攻 |
|------|------|------|------|------|------|
| 猛将（关羽型） | 1200 | 240 | 140 | 180 | 180 |
| 智将（诸葛型） | 1000 | 140 | 260 | 160 | 200 |
| 速将（张辽型） | 1000 | 200 | 180 | 150 | 260 |

## 三、战法分类（三谋实际为 4 类）

### 1. 指挥战法（指）

- **战斗开始时最先发动**，全程生效
- **不受控制状态影响**（只要满足触发条件即可生效，不会被缴械/计穷打断）
- **武将阵亡后指挥战法失效**（⚠️ 重要：这是 sanPoker 下注博弈的重要维度）
- 通常为属性增益、全队加成

### 2. 主动战法（主）

- 武将行动后、普通攻击前按**发动率**触发（典型 30%–45%）
- 部分高阶战法有**准备回合**（延迟发动，准备可被打断）
- 受**计穷**状态影响：计穷下无法发动主动战法
- 未发动则改为普通攻击

### 3. 追击战法（追）

- **武将执行普通攻击之后**按发动率触发
- 与主动战法的关键区别：**必须走普攻才能触发**
- 受**缴械**影响：缴械下无法普通攻击 → 追击战法无法触发
- 主动战法发动时，本回合普攻取消 → 追击战法也不触发（互斥）

### 4. 被动战法（被）

- 触发时机由战法本身定义：
  - 受到攻击时（如"忘私相助"）
  - 攻击时（如"锐不可当"）
  - 施加负面效果时（如"横征暴敛"）
  - 兵力低于阈值、回合开始等
- 部分被动战法无发动率，部分有较高发动率

### ⚠️ sanPoker MVP 简化说明

- MVP **实装 4 类战法**
- 不实装**准备回合**（主动战法一律即时发动）
- 不实装**阵法战法**（属于武将携带品类，三谋中也非独立战法分类）

## 四、伤害计算

### 基础公式（sanPoker 简化版）

```
武力伤害 = (自身武力 × 战法倍率 - 目标统率 × 0.8) × 随机波动 × 增减伤修正
谋略伤害 = (自身智力 × 战法倍率 - 目标统率 × 0.6) × 随机波动 × 增减伤修正
```

- **战法倍率**：每个战法的基础系数，典型范围 80%–200%
- **随机波动**：0.9 ~ 1.1
- **增减伤修正**：增伤 buff / 减伤 buff / 易伤 / 抗性等

### 三谋特有规则（sanPoker 保留）

- **易伤效果比增伤效果略强**（相同数值下）
- **低兵力惩罚**：当前兵力低于一定比例时伤害输出降低（sanPoker MVP 可简化为兵力 < 30% 时输出 ×0.9）
- 单次伤害下限为攻方对应属性的 10%（避免被完全减免）

### 兵种克制（MVP 暂不实装，记录待扩展）

盾 → 弓 → 枪 → 骑 → 盾（克制方伤害 +15%，被克制方 -15%）

### 阵营加成（MVP 暂不实装）

魏 / 蜀 / 吴 / 群，同阵营 3 武将同队时触发加成

## 五、状态效果（三谋术语）

### 负面状态

| 状态 | 类型 | 效果 | sanPoker MVP 持续 |
|------|------|------|-------------------|
| **缴械** | 控制 | 无法**普通攻击**（连带追击战法无法触发） | 2 回合 |
| **计穷** | 控制 | 无法发动**主动战法**（不分武力/谋略） | 2 回合 |
| **禁疗** | 控制 | 无法恢复兵力 | 2 回合 |
| **畏缩** | 减益 | 武力 × 0.7 | 2 回合 |
| **怯战** | 减益 | 智力 × 0.7 | 2 回合 |
| **破军** | 减益 | 统率 × 0.7 | 2 回合 |

### 持续伤害（三谋有 6 种 DoT）

| 类型 | 伤害来源 | 每回合损失 |
|------|----------|-----------|
| **灼烧** | 武力 | 最大兵力 8% |
| **中毒** | 智力 | 最大兵力 6% |
| **沙暴** | 武力 | 最大兵力 6% |
| **溃逃** | 武力 | 最大兵力 7% |
| **水攻** | 智力 | 最大兵力 7% |
| **叛逃** | 智力 | 最大兵力 8% |

> MVP 可只保留**灼烧 + 中毒**，后续扩展再加入其他 DoT。

### 增益状态

| 状态 | 效果 | 持续 |
|------|------|------|
| 暴怒 | 武力 × 1.2 | 2 回合 |
| 奋战 | 智力 × 1.2 | 2 回合 |
| 坚守 | 统率 × 1.3 | 2 回合 |
| 护盾 | 吸收等量伤害后消失 | 至消耗 |

### 状态规则

- **同类状态不叠加**，新状态刷新持续时间
- **异类状态可共存**
- 持续伤害每回合**开始时**结算
- 控制与减益每回合**结束时** `turnsLeft -1`，归零解除

## 六、行动顺序（三谋先攻系统）

### 顺序决定

1. **先手标签**的战法最先执行（如突袭类战法）
2. 按**先攻**从高到低排序
3. **先攻差 > 70** → 先攻高者**必定先手**
4. 先攻差 ≤ 70 → 按比例随机决定先后
5. 先攻完全相同 → 50/50 随机

### 位置修正（sanPoker 定义）

| 位置 | 先攻修正 |
|------|----------|
| 前锋 | × 1.10 |
| 中军 | × 1.00 |
| 大营 | × 0.95 |

## 七、3 个武将 MVP 样本池

> 覆盖"猛将 / 智将 / 速将"三种原型，各携带 **2 个战法**。
> 用于验证 sanPoker 战斗闭环。正式版本将扩充到 15~20 位。

### 武将 1：关羽 🗡️（猛将·蜀·骑兵）

| 属性 | 数值 |
|------|------|
| 兵力 | 1200 |
| 武力 | 240 |
| 智力 | 140 |
| 统率 | 180 |
| 先攻 | 180 |

**战法 A：武圣（指挥）**
- 战斗开始时生效：自身暴击率 +20%，暴击伤害 ×2.0
- 关羽阵亡后失效
- 文案：神威盖世，万人不可挡

**战法 B：拖刀计（主动 · 发动率 35%）**
- 目标：敌方单体（随机）
- 武力伤害，倍率 160%
- 命中后 100% 附加**畏缩**（武力 ×0.7，持续 2 回合）
- 文案：刀回之处，敌将胆寒

### 武将 2：诸葛亮 🪶（智将·蜀·弓兵）

| 属性 | 数值 |
|------|------|
| 兵力 | 1000 |
| 武力 | 140 |
| 智力 | 260 |
| 统率 | 160 |
| 先攻 | 200 |

**战法 C：八阵图（主动 · 发动率 30%）**
- 目标：敌方全体
- 谋略伤害，倍率 90%
- 命中目标 50% 概率附加**计穷**（持续 2 回合）
- 文案：阵法既成，困龙锁云

**战法 D：锦囊妙计（指挥）**
- 战斗开始时生效：我方全体前 3 回合智力 +15%
- 诸葛亮阵亡后失效
- 文案：三计在锦，临危可开

### 武将 3：张辽 ⚡（速将·魏·骑兵）

| 属性 | 数值 |
|------|------|
| 兵力 | 1000 |
| 武力 | 200 |
| 智力 | 180 |
| 统率 | 150 |
| 先攻 | 260 |

**战法 E：突袭（主动 · 先手 · 发动率 40%）**
- 目标：敌方单体（先攻最高者）
- 武力伤害，倍率 130%
- 本回合本战法**必先手**（无视先攻顺序）

- 文案：逍遥津畔，一骑当先

- 触发：战斗开始时
- 效果：敌方全体先攻 -10%，持续 3 回合
- 文案：威名所至，敌寒其胆

## 八、3 个通用战法池

> 不绑定特定武将，供"公共武将"或可换装场景使用。
> 设计理念：效果通用，不破坏任一武将的特色定位。

### 战法 G：铁壁（指挥）

- 装备者统率 +25%，全程持续（装备者阵亡后失效）
- 文案：壁垒森严，万夫莫开

### 战法 H：火攻（主动 · 发动率 35%）

- 目标：敌方随机 2 人
- 谋略伤害，倍率 80%
- 60% 概率附加**灼烧**（每回合 -8% 最大兵力，持续 2 回合）
- 文案：风助火势，燎原之焰

### 战法 I：鼓舞（指挥）

- 我方全体前 4 回合武力 +10%
- 装备者阵亡后失效
- 文案：擂鼓振军，士气如虹

## 九、sanPoker 战斗引擎实装清单

### 必须保留的核心机制

1. 6 个武将位 × 2 战法 = 最多 12 战法参与战斗
2. **4 类战法触发时机不同**（指挥 → 行动 → 主动 → 普攻 → 追击；被动按条件触发）
3. **指挥战法随武将阵亡失效**（影响下注博弈：若你的指挥战法来自低统率武将，对手可以针对性斩首）
4. 8 回合上限 + 平局按剩余兵力
5. **先攻差 > 70 必先手**规则
6. 状态效果同类不叠加、异类共存
7. **缴械打断追击，计穷打断主动**

### MVP 可简化或不实装

1. 兵种克制（盾/弓/枪/骑）—— 后续扩展
2. 阵营加成（魏蜀吴群）—— 后续扩展
3. 准备回合的主动战法 —— 一律即时发动
4. 统率的分项细节（武将等级/加点/缘分）—— 固定属性
5. 6 种 DoT 只保留灼烧 + 中毒，其他后续加

### 为下注博弈保留的设计接口

1. **战斗可快速推演（< 1 秒）**：支持"静默计算"，用于 UI 展示前的结果预演
2. **种子化随机**：同阵容 + 同种子 = 同结果（可复现、可审计、可重放）
3. **步进式结算**：支持"推进 1 回合"接口，方便做战斗动画 / 观战
4. **方差保留**：发动率 30%–45% + 随机波动 ±10% + 暴击 → 约 15%–25% 的结果方差，为诈唬留空间

## 十、后续扩展方向

1. 扩充武将池到 15~20 位，覆盖魏蜀吴群四势力
2. 每位武将 2~3 个备选战法，支持战前换装
3. 加入兵种克制系统（sanPoker 的"武将克制链"）
4. 位置协同（前锋/中军/大营的战法联动效果）
5. 赛季变体战法池（避免固定最优解）
6. "公共武将"专属战法池（独立于玩家卡池）
