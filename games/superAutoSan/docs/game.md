# superAutoSan — 核心系统设计文档

## 一、游戏概述

superAutoSan 是一款网页端单机自走棋游戏，玩法完全复刻 Super Auto Pets（Turtle Pack），主题换为三国。玩家在商店阶段购买武将、使用道具、调整站位，然后进入自动战斗。纯单机无限闯关模式，系统生成递增难度的敌方队伍，看玩家能闯到第几关。

- **单局时长**：20-30 分钟
- **核心循环**：商店准备 → 自动战斗 → 结算 → 下一关
- **美术风格**：像素风，武将用简单色块 + 文字标签表示
- **战斗风格**：击杀表现要夸张，有打击感（参考原版互相撞飞的效果）

## 二、完整游戏流程

```
[标题画面] → [商店阶段] ←→ [自动战斗] → [结算]
                 ↕                          ↓
            [队伍管理]              [胜利 → 下一关]
                                   [失败 → 扣1命]
                                   [0命 → Game Over → 显示最终分数]
```

### 阶段 0：新手教学
- 标题画面点击开始后进入单页教学（`TutorialScreen`）
- 展示模拟顶栏，金币和生命值用 **HighlightBox** 包裹（带方框+脉冲发光动画 + 顶部标签），让玩家一眼定位它们在角落的位置
- 包含若干说明小节：游戏目标、商店阶段（购买 3 金、出售 1 金、同名合并升级）、战斗规则、锁定商店、小提示
- "锁定商店"小节内联渲染示范商店卡，锁定按钮带脉冲高亮
- 用简短文字说明属性颜色（橙色=攻击、红色=生命）以及悬停/手机长按查看技能
- 点击"开始游戏"进入商店阶段

### 阶段 1：开局
- 玩家以 5 条生命、10 金币开始
- 商店展示 Tier 1 武将和道具
- 分数 = 0（当前关卡数）

### 阶段 2：商店准备
- 每回合获得 **10 金币**（不累积）
- 每回合开始自动刷新商店（非免费）
- 手动刷新：**1 金币**
- 购买武将：**3 金币**
- 购买道具：**3 金币**（安眠药 = 1 金币）；糜夫人在场时显示折后价（原价灰色删除线 + 折后价绿色）
- 可自由调整武将站位（拖拽排序）
- 使用道具：点击道具 → 进入目标选择模式（队伍高亮） → 点击目标武将使用
- **出售武将**：拖动到商店区域**任意位置**释放（整个上半部分都是售卖区，拖入时显示红色虚线边框 + 半透明红底 + 居中"松开出售"文字）
- 可冻结（锁定）商店中的武将/道具保留到下回合（点击❄图标）。冻结按钮放大为 20×20 圆形按钮，未锁定灰底白圈、锁定后蓝底雪花
- **升级奖励**：武将升到 Lv2 时获得下一阶武将奖励卡，可与队伍合并；奖励卡触发的合并若再次升级，会**链式触发**新的奖励卡
- **同名升级提示**：商店武将若与队伍中存在同名（且未满级）成员，卡片会有绿框 + 脉冲发光 + 顶部绿色徽章
  - 徽章 `↑升级`：本次合并会触发等级跃迁
  - 徽章 `↑`：仅累积经验，不会升级
- 队伍最多 **5 个**槽位，右侧为前排（与战斗一致）
- 准备完毕后点击"出战"进入战斗

### 阶段 3：自动战斗
- 双方最前方武将**同时互相攻击**（结算同步进行）
- 伤害 = 攻击力，扣对方生命值
- 生命 ≤ 0 → 阵亡，触发阵亡效果
- 同时阵亡的武将一起播放死亡动画
- 后方武将自动前移
- 重复直到一方全灭
- **击杀动画要夸张**：武将被击败时有爆炸效果
- 战斗速度可调：1x(500ms) / 2x(250ms) / 3x(120ms)
- **零延迟事件**：snapshot / knockback / 技能描述 / 锦囊触发 / summon / buff / damage_dealt 全部即时跳过，避免每次召唤/buff 都卡顿一次完整延迟
- **酒等临时增益**带入战斗：商店阶段获得的 tempAtk/tempHp 不再被战斗初始化清零，仅战斗结束时统一清空（实现"持续一回合"语义）

### 阶段 4：回合结算
- **所有我方武将战后复活，HP恢复至最大值**（存活的保留战斗中获得的永久属性变更）
- **胜利**：关卡数 +1，进入下一关商店阶段；**玩家阵容存入 PVE 竞技场**
- **失败**：生命 -1，仍进入下一关商店阶段
- **平局**：不扣生命，进入下一关
- 生命归零 → Game Over，显示最终分数（= 闯过的关卡数）

#### 战斗结算覆盖层
- 战斗结束后，屏幕中央显示半透明黑底覆盖层
- "胜利！"（金色） / "失败..."（红色） / "平局"（灰色）巨型文字（64px，带阴影）
- 下方显示"剩余生命: ♥♥♥♡♡ (3/5)"
- `pointerEvents: none` 不阻挡下方"继续"按钮
- 0.3s 淡入动画

#### 通关庆祝（第 15 关胜利）
- 第 15 关胜利时显示特殊覆盖层："通关！恭喜"
- 副标题："你已征服 15 关，超凡的统帅！"
- 提示后续进入**无尽挑战**模式

### PVE 竞技场系统
- 每个关卡等级存储最多 **20 套**玩家阵容（localStorage 持久化）
- 每条阵容附带 `savedAt` 时间戳
- **无论胜败**，每局战斗结束后都将玩家战前阵容存入对应关卡的竞技场池
- 池未满（< 20 套）时直接追加；已满时替换一套随机阵容
- 生成敌方时优先从竞技场池中随机抽取，无数据时降级到模拟/随机生成
- **来源标识**：当敌方阵容来自竞技场时，敌方区域上方显示蓝色小标签 `⚔ 玩家阵容 · 5分钟前 / 2小时前 / 3天前 / 2026-04-08`，让玩家知道遇到的是谁的历史阵容
- 效果：竞技场阵容反映玩家在各关卡的真实水平，难度逐步趋近玩家实力

### 无尽挑战（第 16 关起）
- 通关 15 关后进入无尽模式，关卡数无上限
- 敌方武将每只单位获得**急剧递增**的属性加成（同时作用于 ATK 和 HP/maxHp）
- 加成公式：`d × 5 + d²`，其中 `d = wave − 15`
  - 第 16 关：+6
  - 第 17 关：+14
  - 第 18 关：+24
  - 第 19 关：+36
  - 第 20 关：+50（接近 MAX_STAT 上限）
- 该加成对所有敌人来源（竞技场 / 模拟 / 随机）统一应用，确保难度一致
- 设计意图：让 20 关成为绝大多数玩家的极限挑战，鼓励反复尝试和阵容优化

### 阶段 5：Game Over
- 显示最终关卡分数
- 显示最终阵容
- 可选择重新开始

## 三、核心机制

### 3.1 商店系统

#### 阶梯解锁（与原版 SAP 完全一致）

| 回合 | 解锁阶 | 商店武将数 | 商店道具数 |
|------|--------|-----------|-----------|
| 1    | Tier 1 | 3         | 1         |
| 3    | Tier 2 | 3         | 1         |
| 5    | Tier 3 | 4         | 1         |
| 7    | Tier 4 | 4         | 2         |
| 9    | Tier 5 | 5         | 2         |
| 11+  | Tier 6 | 5         | 2         |

回合 11 后不再有新 Tier 解锁，玩家通过刷新和合并来继续强化阵容。

#### 出售武将
- Lv1 卖 1 金，Lv2 卖 2 金，Lv3 卖 3 金
- 部分武将有出售触发效果

#### 冻结
- 可冻结商店中任意武将/道具
- 冻结的内容在下回合刷新时保留

### 3.2 合并/升级系统

- 相同武将合并 → 取双方 ATK/HP 较高值 +1
- 经验系统：Lv1 → Lv2 需 2 XP（额外2个同名武将），Lv2 → Lv3 需 3 XP（共 5 XP）
- 每次合并 +1 XP，兵法（巧克力）道具也 +1 XP
- 升到 Lv2 时奖励从下一阶武将中选 1 位
- 属性上限：50/50
- **升级进度条**：队伍中每个武将下方显示 XP 进度条（青色），Lv3 满级后隐藏

### 3.3 战斗系统

#### 触发类型（与原版完全一致）

| 触发 | 时机 |
|------|------|
| 战斗开始 (Start of battle) | 战斗开始前，按 ATK 高→低依次触发 |
| 攻击前 (Before attack) | 攻击动作前 |
| 攻击后 (After attack) | 攻击动作后 |
| 受伤 (Hurt) | 受伤且存活 |
| 阵亡 (Faint) | HP ≤ 0 时 |
| 击杀 (Knock out) | 击杀敌方时 |
| 前方友方阵亡 (Friend ahead faints) | 紧邻前方的友方阵亡 |
| 前方友方攻击 (Friend ahead attacks) | 紧邻前方的友方发动攻击 |
| 友方召唤 (Friend summoned) | 己方场上新增武将 |
| 敌方召唤 (Enemy summoned) | 敌方场上新增武将 |

#### 永久 vs 临时增益
- **永久**：商店阶段获得（跨战斗保留）
- **临时**：战斗中获得（仅当场有效，用白色下划线标识）

### 3.4 装备/锦囊系统
- 每个武将只能携带 **1 个**锦囊（Perk）
- 新锦囊覆盖旧的
- 锦囊效果详见道具列表

### 3.5 生命与计分
- 初始生命：**5**
- 回合 3 开始时若已失去生命，恢复 1 点
- 战斗失败 -1 命，平局不扣
- 生命归零 → Game Over
- **分数 = 闯过的关卡数**，始终在界面上显示

## 八、移动端适配

- **长按 Tooltip**：触屏设备无法 hover，所有 Tooltip 支持 `onTouchStart` 启动 400ms 长按定时器，长按触发后 `preventDefault` 阻止 click 穿透（避免误触购买/出售）；手指滑动取消长按；浮层显示后点击屏幕任意处关闭
- **冻结按钮**：放大为 20×20 圆形按钮，方便手指点击
- **结算覆盖层**：覆盖层 `pointerEvents: none`，下方继续按钮仍可点击

## 九、特殊触发器规则补充

### 9.1 购买触发器
游戏中"购买时"触发器分两类，行为不同：

| 武将 | 触发时机 | 说明 |
|------|---------|------|
| 军需官 | **每次购买任何武将** | 队伍中每个军需官各自触发，给 `level` 个随机友军 +1/+1 |
| 徐庶 | **每次购买任何武将** | 队伍中每个徐庶各自触发，若上局失败则全队 +level/+level |
| 孙尚香 | 仅买入孙尚香时 | 一次性替换商店道具为 2 个免费军粮（+1/+2），重复触发不合理 |

### 9.2 升级奖励链式触发
- 武将升到 Lv2/Lv3 时触发奖励卡（从下一阶武将中挑选）
- **奖励卡也可以触发新的奖励卡**：买入奖励卡若导致合并升级（无论 Lv1→2 或 Lv2→3），系统会立刻刷新一张新的奖励卡
- 实现细节：`buyRewardPet` 在合并前先清空当前奖励，再走升级判定，让 `offerLevelUpReward` 的 `set` 写入新奖励而不被覆盖
