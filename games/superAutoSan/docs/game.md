# superAutoSan — 核心系统设计文档

## 一、游戏概述

superAutoSan 是一款网页端单机自走棋游戏，玩法完全复刻 Super Auto Pets（Turtle Pack），主题换为三国。玩家在商店阶段购买武将、使用道具、调整站位，然后进入自动战斗。纯单机无限闯关模式，系统生成递增难度的敌方队伍，看玩家能闯到第几关。

- **单局时长**：20-30 分钟
- **核心循环**：商店准备 → 自动战斗 → 结算 → 下一关
- **美术风格**：像素风，武将用简单色块 + 文字标签表示
- **战斗风格**：击杀表现要夸张，有打击感（参考原版互相撞飞的效果）

## 二、完整游戏流程

```
[标题画面] → [商店阶段] ←→ [自动战斗] → [结算]
                 ↕                          ↓
            [队伍管理]              [胜利 → 下一关]
                                   [失败 → 扣1命]
                                   [0命 → Game Over → 显示最终分数]
```

### 阶段 1：开局
- 玩家以 5 条生命、10 金币开始
- 商店展示 Tier 1 武将和道具
- 分数 = 0（当前关卡数）

### 阶段 2：商店准备
- 每回合获得 **10 金币**（不累积）
- 每回合开始自动刷新商店（非免费）
- 手动刷新：**1 金币**
- 购买武将：**3 金币**
- 购买道具：**3 金币**（安眠药 = 1 金币）
- 可自由调整武将站位（拖拽排序）
- 使用道具：点击道具 → 进入目标选择模式（队伍高亮） → 点击目标武将使用
- 出售武将：拖动武将到商店区域上方释放
- 可冻结（锁定）商店中的武将/道具保留到下回合（点击❄图标）
- **升级奖励**：武将升到 Lv2 时，自动获得下一阶的随机武将加入队伍
- 队伍最多 **5 个**槽位，右侧为前排（与战斗一致）
- 准备完毕后点击"出战"进入战斗

### 阶段 3：自动战斗
- 双方最前方武将**同时互相攻击**（结算同步进行）
- 伤害 = 攻击力，扣对方生命值
- 生命 ≤ 0 → 阵亡，触发阵亡效果
- 同时阵亡的武将一起播放死亡动画
- 后方武将自动前移
- 重复直到一方全灭
- **击杀动画要夸张**：武将被击败时有爆炸效果
- 战斗速度可调：1x / 2x / 3x

### 阶段 4：回合结算
- **所有我方武将战后复活**（死亡的恢复为战前HP，存活的保留战后HP）
- **胜利**：关卡数 +1，进入下一关商店阶段
- **失败**：生命 -1，仍进入下一关商店阶段
- **平局**：不扣生命，进入下一关
- 生命归零 → Game Over，显示最终分数（= 闯过的关卡数）

### 阶段 5：Game Over
- 显示最终关卡分数
- 显示最终阵容
- 可选择重新开始

## 三、核心机制

### 3.1 商店系统

#### 阶梯解锁（与原版 SAP 完全一致）

| 回合 | 解锁阶 | 商店武将数 | 商店道具数 |
|------|--------|-----------|-----------|
| 1    | Tier 1 | 3         | 1         |
| 3    | Tier 2 | 3         | 1         |
| 5    | Tier 3 | 4         | 1         |
| 7    | Tier 4 | 4         | 2         |
| 9    | Tier 5 | 5         | 2         |
| 11+  | Tier 6 | 5         | 2         |

回合 11 后不再有新 Tier 解锁，玩家通过刷新和合并来继续强化阵容。

#### 出售武将
- Lv1 卖 1 金，Lv2 卖 2 金，Lv3 卖 3 金
- 部分武将有出售触发效果

#### 冻结
- 可冻结商店中任意武将/道具
- 冻结的内容在下回合刷新时保留

### 3.2 合并/升级系统

- 相同武将合并 → 取双方 ATK/HP 较高值 +1
- 经验系统：Lv1 → Lv2 需 2 XP（额外2个同名武将），Lv2 → Lv3 需 3 XP（共 5 XP）
- 每次合并 +1 XP，兵法（巧克力）道具也 +1 XP
- 升到 Lv2 时奖励从下一阶武将中选 1 位
- 属性上限：50/50
- **升级进度条**：队伍中每个武将下方显示 XP 进度条（青色），Lv3 满级后隐藏

### 3.3 战斗系统

#### 触发类型（与原版完全一致）

| 触发 | 时机 |
|------|------|
| 战斗开始 (Start of battle) | 战斗开始前，按 ATK 高→低依次触发 |
| 攻击前 (Before attack) | 攻击动作前 |
| 攻击后 (After attack) | 攻击动作后 |
| 受伤 (Hurt) | 受伤且存活 |
| 阵亡 (Faint) | HP ≤ 0 时 |
| 击杀 (Knock out) | 击杀敌方时 |
| 前方友方阵亡 (Friend ahead faints) | 紧邻前方的友方阵亡 |
| 前方友方攻击 (Friend ahead attacks) | 紧邻前方的友方发动攻击 |
| 友方召唤 (Friend summoned) | 己方场上新增武将 |
| 敌方召唤 (Enemy summoned) | 敌方场上新增武将 |

#### 永久 vs 临时增益
- **永久**：商店阶段获得（跨战斗保留）
- **临时**：战斗中获得（仅当场有效，用白色下划线标识）

### 3.4 装备/锦囊系统
- 每个武将只能携带 **1 个**锦囊（Perk）
- 新锦囊覆盖旧的
- 锦囊效果详见道具列表

### 3.5 生命与计分
- 初始生命：**5**
- 回合 3 开始时若已失去生命，恢复 1 点
- 战斗失败 -1 命，平局不扣
- 生命归零 → Game Over
- **分数 = 闯过的关卡数**，始终在界面上显示

## 六、升级能力缩放

与原版 SAP 完全一致：
- **属性加成**：Lv1 → Lv2 翻倍，Lv3 三倍
- **伤害类**：翻倍/三倍
- **召唤物属性**：同步提升
- **重复次数**：增加
- **百分比**：递增
- **范围**：扩大

## 七、界面设计要点

### 7.1 主要界面

1. **标题画面**：游戏名 + 开始按钮
2. **商店界面**（核心）：
   - 上方：商店区域（武将卡 + 道具卡 + 刷新按钮 + 冻结按钮）
   - 中间：己方队伍 5 槽位（可拖拽排序）
   - 下方：金币数、回合数、生命数、当前关卡/分数
   - 右侧：出战按钮
3. **战斗界面**：
   - 己方队伍（左） vs 敌方队伍（右）
   - 武将用色块 + 文字标签表示
   - ATK/HP 数字显示在武将下方
   - **击杀动画：撞飞/爆炸效果，要夸张有打击感**
   - 战斗自动进行，可调速（1x/2x/3x）
4. **Game Over 界面**：最终分数 + 最终阵容 + 重新开始

### 7.2 武将卡片显示
- 色块背景（按 Tier 区分颜色）
- 武将名称（文字）
- ATK（左下）/ HP（右下）
- 等级星标（★/★★/★★★）
- 锦囊图标（若有）
- **XP 进度条**：卡片底部青色横条，显示升级进度（Lv3 满级后隐藏）
- **悬停提示**：鼠标悬停显示详细信息（武将名、Tier、属性、技能描述、锦囊、出售价格）

### 7.2.1 道具卡片显示
- 色块背景（按类型区分：属性=绿，锦囊=棕，特殊=紫）
- 道具名称（文字）
- 费用
- **悬停提示**：鼠标悬停显示详细效果描述
