# Super Auto Pets 机制参考文档

> 本文档用于 superAutoSan 开发参考，数据基于 Turtle Pack（基础包）。

---

## 一、核心循环

商店阶段（准备） → 战斗阶段（自动） → 循环，直到玩家获胜或生命耗尽。

### 基础规则
- 初始生命：5（普通/困难）、7（简单）
- 胜利条件：获得 10 个奖杯
- 失败扣 1 生命，平局不扣
- 回合 3 开始时若已失去生命，恢复 1 点

### 商店阶段
- 每回合 **10 金币**（不累积）
- 宠物价格：**3 金币**
- 食物价格：**3 金币**（安眠药 = 1 金币）
- 刷新商店：**1 金币**（每回合开始免费刷新一次）
- 可冻结商店中的宠物/食物，保留到下回合
- 队伍最多 **5 个**槽位
- 可自由调整宠物站位

### 出售宠物
- 等级 1 卖 1 金，等级 2 卖 2 金，等级 3 卖 3 金
- 部分宠物有 Sell 触发效果

### 合并/升级
- 将相同宠物合并可升级
- 合并时取双方攻击/生命的较高值，再 +1/+1
- 经验系统：Lv1 → Lv2 需要 2 XP，Lv2 → Lv3 需要 3 XP（共 5 XP）
- 每次合并 +1 XP，巧克力食物也 +1 XP
- 升到 Lv2 时，奖励从下一阶宠物中选 1 只
- 属性上限：50/50

### 阶梯解锁

| 回合 | 解锁阶 |
|------|--------|
| 1    | Tier 1 |
| 3    | Tier 2 |
| 5    | Tier 3 |
| 7    | Tier 4 |
| 9    | Tier 5 |
| 11+  | Tier 6 |

## 二、战斗机制

### 自动战斗流程
1. **战斗开始**：所有"Start of battle"触发按攻击力从高到低依次激活（平局随机）
2. **主循环**：双方最前方宠物互相攻击，伤害 = 攻击力，扣对方生命值
3. 生命 ≤ 0 → 死亡（Faint），触发死亡效果，后方宠物前移
4. 重复直到一方全灭

### 触发类型

| 触发 | 时机 |
|------|------|
| Start of battle | 战斗开始前 |
| Before attack | 攻击前 |
| After attack | 攻击后 |
| Hurt | 受伤且存活 |
| Faint | 死亡时 |
| Knock out | 击杀敌方时 |
| Friend ahead faints | 前方友方死亡 |
| Friend ahead attacks | 前方友方攻击 |
| Friend summoned | 友方召唤新宠物 |
| Enemy summoned | 敌方召唤新宠物 |

### 永久 vs 临时增益
- **永久增益**：商店阶段获得的属性加成，跨战斗保留
- **临时增益**：战斗中获得的属性加成，仅当场有效

### 装备/Perk 系统
- 每个宠物只能携带 **1 个** Perk
- 新 Perk 会覆盖旧的

## 五、升级能力缩放规则

- **属性加成**：Lv1 → Lv2 翻倍，Lv3 三倍（如火烈鸟 +1/+1 → +2/+2 → +3/+3）
- **伤害类**：翻倍/三倍（如刺猬 2 → 4 → 6）
- **召唤物属性**：同步提升（如蟋蟀 1/1 → 2/2 → 3/3）
- **重复次数**：增加（如蚊子 1 → 2 → 3 个目标）
- **百分比**：递增（如臭鼬 33% → 66% → 99%）
- **范围**：扩大（如长颈鹿 1 → 2 → 3 个前方友方）

## 六、经典组合

- **大象 + 骆驼/河豚/孔雀**：大象攻击后伤害后方友方，触发 Hurt
- **火鸡 + 绵羊/蟋蟀/鹿**：火鸡给召唤物 +3/+3
- **马 + 蟋蟀/绵羊**：马给召唤物 +1 ATK（临时）
- **狗 + 召唤流**：每次召唤狗 +1/+1
- **老虎 + 蛇**：蛇的能力触发两次
- **鲸鱼 + 强力前排**：鲸鱼吞噬再释放，等于第二条命
- **鹿（巴士 + 辣椒）**：5/5 巴士打前排，辣椒打后排
- **苍蝇 + 死亡流**：友方死亡 → 4/4 僵尸苍蝇补位
- **安眠药 + 蟋蟀/绵羊**：在商店触发 Faint 召唤免费宠物
- **罐头叠加**：多次购买，后续商店宠物越来越强
