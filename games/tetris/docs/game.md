# 俄罗斯方块 / Tetris · 核心系统设计

## 一、游戏概述

传统单机版俄罗斯方块。玩家操控从顶部降落的方块，将其拼合成完整的横行以消除得分，方块越堆越快，直到堆到顶部游戏结束。

- **模式**：单人 Marathon（无尽，等级持续上升）
- **目标**：尽可能多地得分 / 消除更多行数
- **结束**：新方块无法在出生位置生成（Top Out）

## 二、棋盘 Playfield

| 项 | 值 |
|---|---|
| 列数 | 10 |
| 可见行数 | 20 |
| 缓冲行（顶部不可见） | 2 |
| 单元格尺寸 | 32px（可缩放） |
| 坐标系 | 左上角为 (0,0)，x 向右，y 向下 |

## 三、方块 Tetromino

共 7 种，颜色遵循 Tetris Guideline 标准：

| 类型 | 形状 | 颜色 | HEX |
|---|---|---|---|
| I | ████ | 青 Cyan | #00F0F0 |
| O | 2×2 方块 | 黄 Yellow | #F0F000 |
| T | T 形 | 紫 Purple | #A000F0 |
| S | S 形 | 绿 Green | #00F000 |
| Z | Z 形 | 红 Red | #F00000 |
| J | J 形 | 蓝 Blue | #0000F0 |
| L | L 形 | 橙 Orange | #F0A000 |

每个方块有 4 个旋转状态（0 / R / 2 / L）。

## 四、随机生成：7-bag

- 一个"袋子"装 7 种方块各一个，随机打乱后依次发牌
- 袋子空后重新装袋
- 效果：任何 7 个连续方块中每种恰好出现一次，避免长时间不出 I（俗称"干旱"）

## 五、旋转系统：SRS（Super Rotation System）

- 每个方块有 4 个朝向状态：`0`, `R`, `2`, `L`
- 旋转时若目标位置被占用，按 **踢墙表 Wall Kick Table** 依次尝试 5 个偏移量
- I 方块使用独立踢墙表
- O 方块不参与旋转（自身对称）

## 六、下落与锁定

### 重力 Gravity
- 自动每隔 `dropInterval` 毫秒下落 1 格
- `dropInterval` 随等级下降（见下表）

### 等级速度表（简化 NES 风格）
| Level | 间隔(ms) |
|---|---|
| 1 | 1000 |
| 2 | 850 |
| 3 | 700 |
| 4 | 600 |
| 5 | 500 |
| 6 | 400 |
| 7 | 300 |
| 8 | 220 |
| 9 | 150 |
| 10 | 120 |
| 11-13 | 100 |
| 14-16 | 80 |
| 17-19 | 60 |
| 20+ | 50 |

### 锁定延迟 Lock Delay
- 方块触底后，500ms 后锁入棋盘
- 在锁定延迟期间任何成功的移动/旋转会**重置**计时器
- 重置次数上限：15 次（防止无限延迟）

## 七、操作 Controls

| 按键 | 功能 |
|---|---|
| ← / → | 左右移动 |
| ↓ | 软降（2× 重力，每格 +1 分） |
| ↑ / X | 顺时针旋转 |
| Z | 逆时针旋转 |
| Space | 硬降（瞬间落底，每格 +2 分） |
| C / Shift | Hold（暂存方块） |
| P / Esc | 暂停 |
| R | 重新开始（Game Over 后） |

**DAS/ARR（自动位移）**：
- DAS (Delayed Auto Shift)：长按方向键 167ms 后开始连续移动
- ARR (Auto Repeat Rate)：连续移动每 33ms 一格

## 八、Hold 暂存

- 按 Hold 键把当前方块放入左侧 Hold 槽
- 若槽为空，立即从队列取下一个方块；若槽有方块，当前与槽内交换
- **每个方块只能 Hold 一次**，锁定后重置

## 九、Next 预览

- 右侧显示队列中接下来的 **5** 个方块
- 每次从 7-bag 中取出后队列补齐

## 十、Ghost 影子

- 在当前方块正下方显示其最终落点的半透明轮廓
- 方便玩家预判落点

## 十一、消行 Line Clear

- 锁定后检测整行填满的行
- 消除后上方所有行下移
- **消行数决定得分倍率**（见下节）

## 十二、计分 Scoring

| 动作 | 基础分 |
|---|---|
| Single（1 行） | 100 × level |
| Double（2 行） | 300 × level |
| Triple（3 行） | 500 × level |
| **Tetris**（4 行） | 800 × level |
| Soft Drop | 每格 1 分 |
| Hard Drop | 每格 2 分 |

### 等级 Level
- 初始 Level 1
- **每消除 10 行**等级 +1，下落速度加快

## 十三、游戏流程

```
[Idle 主菜单]
    ↓ Start
[Playing 游戏中] ←→ [Paused 暂停]
    ↓ Top Out
[Game Over]
    ↓ Retry
[Playing]
```

### 视觉风格
- 深色背景（#0b0e14 类似暗夜）
- 方块带高光与阴影，增强立体感
- 消行时高亮闪烁动画（200ms）
- Hard Drop 时方块路径留下残影
- Game Over 时棋盘从下往上灰化
