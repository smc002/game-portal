# 机关列表 — 单机演示版

> **演示版说明**：所有机关效果在单机演示中为纯展示。运转时以飘字形式显示效果文字，在运转记录和今日能力面板中可查看详情。原版中涉及沙盘/战斗的实际效果在演示版中仅作为文本展示。

## 品质与等级

- 所有非珍宝机关初始白色（1 级），可升级：蓝色（2 级）→ 紫色（3 级）→ 橙色（4 级）→ 红色（5 级，满级）
- 获得重复机关时自动升级
- 珍宝无等级，使用一次即销毁

## 分数规则

- 每个等级的机关有基础分数（配置）
- 触发特殊条件时有额外分数（配置）
- 珍宝有固定分数（配置）

## 兵书类（展示：作战指令）

兵书类升级效果统一增加指令使用次数。触发特殊效果时，在今日能力面板产生两个条目：可使用指令 + 持续加成。

### 孙子兵法

- **类型**：兵书
- **效果**：获得【奔袭】指令 ×1

- **特殊效果**：所有武将先攻+5
- **升级效果**：增加指令次数
- **简略描述**：N 次奔袭 / 先攻+5

### 兵囤指南

- **类型**：兵书

- **升级效果**：增加指令次数
- **简略描述**：N 次重整 / 武力+5

### 鲁班经

- **类型**：兵书
- **效果**：获得【修复】指令 ×1（为沙盘建筑恢复耐久）

- **升级效果**：增加指令次数
- **简略描述**：N 次修复 / 统率+5

### 太平要术

- **类型**：兵书
- **效果**：获得【玄术】指令 ×1（1 级传送 2 次，5 级传送 10 次）

## 特殊条件判定规则

以下判定逻辑在演示版中完整保留，用于决定是否触发特殊效果的飘字和高亮：

1. **相邻判定**：槽位线性排列，位置 i 的相邻槽位为 i-1 和 i+1
2. **边缘判定**：槽位 1 和最后一个已开放槽位为边缘
3. **类型唯一判定**：天机盒中同类型机关（不含珍宝）仅有 1 个
4. **四类齐全判定**：天机盒中存在兵书、算筹、符节、奇械四种类型
5. **空位判定**：相邻槽位未放置机关，或相邻位置超出已开放范围（视为边缘/空位）
