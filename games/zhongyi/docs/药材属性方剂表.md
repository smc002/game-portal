# 药材属性-方剂 对照表

| 药材名称 | 药性/性质 (属性) | 适用症状 (主治) | 对应经典方剂 (完整配方内容) |
| :--- | :--- | :--- | :--- |
| **人参** | 微温；甘、苦 | 大补元气、气虚欲脱、脾虚泄泻 | **【生脉散】**：人参、麦冬、五味子 |
| **黄芪** | 微温；甘 | 补气升阳、固表止汗、托毒生肌 | **【补中益气汤】**：黄芪、人参、白术、炙甘草、当归、陈皮、升麻、柴胡 |
| **当归** | 温；甘、辛 | 补血活血、调经止痛、润肠通便 | **【四物汤】**：当归、熟地黄、白芍、川芎 |
| **熟地黄** | 微温；甘 | 滋阴补血、益精填髓 | **【六味地黄丸】**：熟地黄、山茱萸、山药、泽泻、茯苓、牡丹皮 |
| **附子** | 大热；辛、甘 (有毒) | 回阳救逆、补火助阳、散寒止痛 | **【四逆汤】**：附子、干姜、炙甘草 |
| **柴胡** | 微寒；苦、辛 | 疏肝解郁、升阳举陷、和解少阳 | **【小柴胡汤】**：柴胡、黄芩、半夏、人参、炙甘草、生姜、大枣 |
| **黄连** | 寒；苦 | 清热燥湿、泻火解毒 | **【黄连解毒汤】**：黄连、黄芩、黄柏、栀子 |
| **半夏** | 温；辛 (需炮制) | 燥湿化痰、降逆止呕、消痞散结 | **【二陈汤】**：半夏、陈皮、茯苓、炙甘草、生姜、乌梅 |
| **金银花** | 寒；甘 | 清热解毒、凉散风热 | **【银翘散】**：金银花、连翘、桔梗、薄荷、竹叶、甘草、荆芥穗、淡豆豉、牛蒡子 |
| **酸枣仁** | 平；甘、酸 | 养心安神、敛汗、生津 | **【酸枣仁汤】**：酸枣仁、茯苓、知母、川芎、甘草 |
| **石膏** | 大寒；辛、甘 | 清热泻火、除烦止渴 | **【白虎汤】**：石膏、知母、炙甘草、粳米 |
| **大黄** | 寒；苦 | 泻下攻积、清解酷热、活血化瘀 | **【大承气汤】**：大黄、芒硝、枳实、厚朴 |
| **桃仁** | 平；苦、甘 | 活血祛瘀、润肠通便、止咳平喘 | **【桃核承气汤】**：桃仁、大黄、桂枝、炙甘草、芒硝 |
| **白术** | 温；甘、苦 | 健脾益气、燥湿利水、止汗安胎 | **【四君子汤】**：人参、白术、茯苓、炙甘草 |
| **茯苓** | 平；甘、淡 | 利水渗湿、健脾、宁心安神 | **【五苓散】**：茯苓、猪苓、泽泻、白术、桂枝 |
| **桂枝** | 温；辛、甘 | 发汗解肌、温通经脉、助阳化气 | **【桂枝汤】**：桂枝、芍药、炙甘草、生姜、大枣 |
| **百合** | 微寒；甘 | 养阴润肺、清心安神 | **【百合地黄汤】**：百合、生地黄汁 |
| **龙胆草** | 寒；苦 | 清翳、泻肝胆火、除下焦湿热 | **【龙胆泻肝汤】**：龙胆草、黄芩、栀子、泽泻、木通、车前子、当归、生地黄、柴胡、甘草 |
